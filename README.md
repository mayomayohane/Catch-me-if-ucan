# リアル探してください（仮） — Catch me if u can

GPS連動のリアル鬼ごっこ（現代版ドロケイ）。5人が「逃走者」と「追跡者」に分かれ、半径3kmのエリアで遊びます。

## 起動

```bash
npm install
npm run dev        # http://localhost:5173 (クライアント) + :8787 (サーバー)
npm test           # ルール・サーバーのテスト
npm run build && npm start   # 本番: http://localhost:8787 で配信
```

- スマホで位置情報・カメラを使うには **HTTPS** が必要です（localhost は例外）。実機テストは ngrok / Cloudflare Tunnel などで公開してください。
- `PHOTO_INTERVAL_SEC=30 npm start` のように指定すると、自撮りミッションの間隔（通常10分）を短縮できます（デモ・テスト用）。

## 構成

| パス | 役割 |
| --- | --- |
| `src/shared/game.ts` | ルール（Haversine距離・エリア判定・チーム定員・ミッション時刻）。サーバーとクライアントで共通 |
| `src/shared/protocol.ts` | WebSocket / HTTP のメッセージ型 |
| `server/room.ts` | ルームの状態機械（ロビー → ゲーム中 → 終了）。**サーバーが唯一の判定者** |
| `server/app.ts` | HTTP + WebSocket サーバー、写真アップロード（`POST /api/photo`）、静的配信 |
| `src/client/` | React + Leaflet(OpenStreetMap) のモバイルWeb UI（ホーム / ロビー / ゲーム / リザルト） |

## 仕様の実装状況

| 仕様 | 実装 |
| --- | --- |
| 1vs4 / 2vs3 / 3vs2、定員超過で役割ロック | ✅ |
| 中心ピン（タップ / 検索 / 現在地）、半径スライダー（既定3.0km, 0.5〜10km） | ✅ 検索は OSM Nominatim |
| 30 / 45 / 60分タイマー、全員準備完了でスタート | ✅ |
| エリア外 → 追跡者画面に赤ピン + 警報音 + 振動（復帰まで継続） | ✅ サーバー側で Haversine 判定 |
| 10分ごとの自撮り強制ポップアップ → ヒントログ・地図のカメラピンで共有 | ✅ 未提出分は残り続ける |
| 確保完了ボタン | ✅ 追跡者が申請 → 逃走者が自分の端末で承認すると成立（60秒で失効） |
| リザルト: 勝利チーム・移動軌跡プレイバック・自撮りハイライト | ✅ 再生スライダー付き |
| 通信切断からの自動復帰 | ✅ 端末ごとの秘密キーで同じプレイヤーに再接続 |

### 仕様に明記がなく、こちらで決めたルール
- 逃走者には追跡者の位置は見えない。同じチームの仲間の位置は見える。
- 追跡者が逃走者の位置を見られるのはエリア外のときだけ（あとは自撮りの撮影地点）。
- 確保された逃走者はアウト（観戦）。全員確保で追跡者の勝ち、時間切れで逃走者の勝ち。

## 既知の制約・次のステップ
- **バックグラウンド位置取得**: ブラウザは画面オフ中に GPS を止めます。ゲーム中は Wake Lock で画面を点けたままにしていますが、本当のバックグラウンド追跡には Capacitor / React Native 等のネイティブラッパーが必要です。
- **永続化**: ルームはメモリ上、写真はローカルディスク（`data/photos`）。本番では Firebase / Supabase / S3 などに置き換えてください（`server/app.ts` の `handlePhoto` が保存処理の差し替えポイントです）。
- 地図タイルは OSM 公式サーバーを使っています。利用規約上、公開運用時は商用タイルプロバイダ（MapTiler 等）への切り替えを推奨します。
